## Средн.10. Класс-итератор

`number_iterator.py`: `NumberIterator(start, stop, step)` выдаёт целые числа
до `stop`, не включая его, как `range`. Реализованы `__iter__` и `__next__`;
итератор однопроходный, поддерживает положительный и отрицательный шаг.

```text
$ python number_iterator.py
По возрастанию: [1, 2, 3, 4, 5]
По убыванию: [5, 3, 1]
```

## Средн.2. Класс «Студент»

`student.py`: `Student` хранит имя и группу. Метод `info()` формирует строку,
а `show_info()` выводит её на экран. Пустые имя и группу класс не принимает.

```text
$ python student.py
Ксения Грозная, группа 221141
```

## Средн.8. Класс-счётчик

`counter.py`: `Counter` изменяет целое значение через `increment()` и
`decrement()`. Оба метода возвращают новое значение, а свойство `value`
показывает текущее. Шаг должен быть положительным целым числом.

```text
$ python counter.py
Начало: 3
После увеличения на 4: 7
После уменьшения на 2: 5
```

## Повыш.3. Система заказов «Товар/Корзина»

`orders.py`: неизменяемый `Product` хранит название и цену, `Basket` добавляет
и удаляет товары с учётом количества. Повторное добавление одного товара
увеличивает его количество; `lines` возвращает снимок позиций. Свойства
`quantity` и `total` вычисляют количество и стоимость текущей корзины.
Цены считаются с `Decimal`, поэтому копейки не теряются из-за двоичной
арифметики. Для цены подходят целое число, строка или `Decimal`; `float`
я не принимаю, чтобы не получить случайное округление.

```text
$ python orders.py
Чай: 2 × 119.90 ₽
Хлеб: 1 × 80.20 ₽
Итого: 320.00 ₽
```

## Повыш.10. Unit-тесты классов (TDD)

Сначала я добавила тесты в ветки, проверила ожидаемое падение, затем
реализовала классы и получила успешный результат. Коммиты и результаты
обоих циклов описаны в [отчёте о TDD](docs/tdd.md). В `tests/` 23 проверки:
обычные сценарии, крайние значения, ошибки типов и сохранность корзины
после отклонённой операции.

```sh
python -m unittest discover -s tests -v
```

Для проверки стиля можно установить только `flake8`:

```sh
python -m pip install -r requirements-dev.txt
flake8 .
```

Программа использует Python 3.10 или новее и стандартную библиотеку.
Разработка велась в ветках `feature/core-classes` и `feature/order-system`;
обе слиты в `main` с отдельными merge-коммитами. Файлы `setup.cfg` и
`requirements-dev.txt` задают проверку стиля.
